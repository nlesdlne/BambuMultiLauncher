## 1. 选题定位（决定 80% 的流量）

### 1.1 你已经有的最强素材：真实痛点

不要从"我做了个软件"开始，从**你的真实处境**开始：

> 公司那台打印机绑的是同事的拓竹账号，公司同事都习惯登那个号发任务；我自己家的打印机绑的是我自己的号。Win 电脑一次只能登一个账号，切一次号就要退一次、登一次、收一次验证码。手机应用双开也没用——因为我经常要发自己画的模型，手机端只能发 MakerWorld 上的开源模型。

这段话是**天然的 15 秒钩子**，几乎不用改就是口播。

### 1.2 标题公式（B站）

痛点 + 具体数字/反差 + 结果。候选（选 1 主 1 备，做 A/B）：

1. 一台电脑同时登录两个拓竹账号？我做了个 150KB 的小工具（免费开源）
2. 公司号是同事的，家里号是我的：拓竹双账号免切换方案
3. 告别验证码：拓竹 Bambu Studio 多账号并行启动器
4. 我给拓竹写了个「多账号启动器」，同事的号一个字节都没动
5. 拓竹双账号党救星：两个窗口同时在线，互不顶号
6. 从 PowerShell 脚本到 150KB 软件：我的拓竹多账号踩坑记录

封面文案（大字，白底绿字/深色底）：

- 主：**一台电脑 两个拓竹账号**
- 副：不用切号 · 不用验证码 · 150KB 免安装
- 角标：开源免费

### 1.3 标题/文案（抖音）

抖音标题不是"标题"，是**第一句话 + 封面字**。候选：

`#拓竹` `#BambuLab` `#3D打印` `#BambuStudio` `#3D打印机` `#开源软件` `#效率工具` `#程序员日常`

### 1.5 参考的同类视频（不是抄，是看结构）

- B站《拓竹bambu handy账号和bambu studio账号不统一，导致我电脑端链接不上打印机》——典型的"账号不统一"痛点型选题，评论区常年有人问，说明**这个痛点有稳定搜索量**。

### 2.2 口播全文（可直接给 TTS）

> 一台 Windows 电脑，同时登录两个拓竹账号——左边是公司的，右边是我自己的。
>
> 以前要这样：退出、重新登录、手机收验证码、再输入。一天来回几趟，人都麻了。更麻烦的是，公司那个号是同事的，验证码还得找他要。
>
> 有人说手机应用双开不就行了？不行。我经常发自己画的模型，手机端只能发 MakerWorld 上的开源模型。
>
> 后来我搞明白了：拓竹的登录状态不在账号系统里，而是在电脑上的一个数据目录里，就是这个 BambuNetworkEngine.conf。所以只要给每个账号准备一份独立的数据目录，再让 Studio 用 --datadir 指向它，登录状态就互不干扰了。
>
> 我把这个思路做成了软件。150KB，单文件，不用安装。第一次打开跟着三步走：它会自己找到你电脑上的 Bambu Studio、找到现有的数据目录，你给它起个名字就行。
>
> 之后就这样：列表里点一下，窗口就起来了。两个账号各开一个窗口，各发各的任务，互不顶号。第一次在新账号里登录一次，以后就一直记住。
>
> 我知道这类工具有个坑：每台电脑环境不一样。所以我加了自诊断——起不来的话，右键跑一次诊断，它会告诉你：进程是不是崩了、退出码是多少、是不是老版本的单实例开关在作怪，能修的直接帮你修掉。
>
> 还有几个细节：以前装过、或者用过脚本留下的账号目录，它会自动认回来；登录列会区分"真登录"和那种 32 字节的空壳文件；启动方式有两种，双击方式不行会自动换常规方式重试。
>
> 免费开源，MIT 协议，GitHub 上搜「拓竹多账号启动器」就能下。用得上就点个 Star，帮到同事就转给他。

**录制技巧**

- 录屏用 OBS（1080p60，只录窗口）或 Win+G；系统缩放建议 100% 或 125%，太大会让字糊。

- 手机验证码那段：拍手机时**把号码后四位遮住**。

## 7. 合规与雷区（务必看）

1. **不要**出现"破解、绕过验证码、免验证、多开器外挂"这类词——会被平台判违规，也会让人误以为是盗号工具。
2. 正确说法：**"多账号启动器 / 多实例管理 / 官方 --datadir 参数隔离数据目录"**。
3. **不要**在抖音放任何外部下载链接；B站简介可以放 GitHub 链接。
4. 涉及公司账号：**不要**展示公司名、同事姓名、真实邮箱、企业内网信息。
5. 声明非官方：视频里说一句"这是个人做的开源小工具，不是拓竹官方产品"，能省掉很多麻烦。
6. 边界要讲清楚（也显得专业）：**不能共享打印机**、**不需要也不建议改账户绑定**、打印机仍需云端在线。

## 8. 一页速用卡（拍视频时贴在显示器上）

- 钩子：**一台电脑，同时开两个拓竹账号**
- 痛点：切号 = 退出 + 登录 + 验证码（公司号还是同事的）
- 原理：登录态在数据目录 → 一个号一份目录 → `--datadir`
- 演示：点一下 → 多开一个窗口 → 各发各的任务
- 差异化：自动认旧数据 / 自动修单实例 / 两种启动方式 / 内置诊断
- 边界：不共享打印机、不改绑定、打印机要在线
- 结尾：**GitHub 搜「拓竹多账号启动器」**（B站简介放链接）
