## 相对交接包 v1.0.5 的改动

产品代码（`src\*.cs`）与 v1.0.5 完全一致。除仓库结构整理（README/LICENSE/CHANGELOG 从 `docs\` 移到根目录、免责声明拆到 `NOTICE`）外，只动了构建工具：

1. **`tools\make_icon.py`** 不再把输出路径写死为本机 `D:\DeepSeek\...\src\app.ico`，改成按脚本位置定位到本项目 `src\app.ico`，先写 `.tmp` 再原子替换。
2. **`build.bat`** 的图标步骤移到编译**之前**、检查真实退出码、默认沿用现有图标（只有缺失或 `build.bat /icon` 时才重生成）。
3. **`tools\make-sleeper.bat`** 新增：从 `tools\sleeper.cs` 编译 `tests\bambu-sleeper.exe`，供本地自检与 CI 使用（原先自检提示里提到这个脚本却不存在）。

## 怎么用

```bat
:: 编译（默认不重生成图标，产物与发布版同字节 153,600 B）
build.bat

:: 重新生成图标后再编译（需要 Python + Pillow）
build.bat /icon
```

自检（17 项，退出码 = 失败数；必须用全新空目录，测试桩放在目录根）：

```bat
tools\make-sleeper.bat
mkdir _selftest
copy tests\bambu-sleeper.exe _selftest\
dist\拓竹多账号启动器.exe --selftest "%CD%\_selftest"
```

截图重新生成：

```bat
dist\拓竹多账号启动器.exe --render "%CD%\_render"
```
